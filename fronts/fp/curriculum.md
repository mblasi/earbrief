# Curriculum — Functional System Design + AI Applications

**Profile:** Mid-senior engineer transitioning toward functional architecture. Solid on OOP and imperative patterns; building depth in function composition, type systems, immutability, and domain-driven design. **New scope:** Functional programming applied to AI systems — training pipelines, data transformations, agent design, and ML infrastructure.

Target: practical patterns that change how you design systems. Functional principles for building reliable, testable, composable AI infrastructure.

The weekly deep-dive routine takes the **first unchecked item**, writes a ~20-minute spoken episode on it, and checks it off. Reorder freely to re-prioritize. Items promoted from the news get inserted wherever they fit.
