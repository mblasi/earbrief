# Curriculum — Functional System Design

Profile: Mid-senior engineer transitioning toward functional architecture. Solid on OOP and imperative patterns; building depth in function composition, type systems, immutability, and domain-driven design. Target: practical patterns that change how you design systems.

The weekly deep-dive routine takes the **first unchecked item**, writes a ~20-minute spoken episode on it, and checks it off. Reorder freely to re-prioritize. Items promoted from the news get inserted wherever they fit.

## Track A — Foundations & Type Systems

- [ ] A1. The function: signatures, composition, and the type as a specification
- [ ] A2. Immutability and persistent data structures: why and when it matters
- [ ] A3. Algebraic Data Types (ADTs): sum types, product types, and modeling domains
- [ ] A4. Monoids and semigroups: the algebra of combining things
- [ ] A5. Functors, applicatives, and monads: abstraction without the mystique

## Track B — Domain-Driven Design for Functional Systems

- [ ] B1. Events, aggregates, and event sourcing in a functional context
- [ ] B2. Value objects and entities: modeling domain boundaries
- [ ] B3. Domain-driven design patterns in functional languages
- [ ] B4. Ubiquitous language: types as documentation

## Track C — Architecture & Refactoring

- [ ] C1. Hexagonal architecture with functional constraints
- [ ] C2. Effect systems and IO: structuring side effects
- [ ] C3. Dependency injection without frameworks: using functions and composition
- [ ] C4. Data-driven design: separating logic from execution
- [ ] C5. Refactoring toward functional: patterns for legacy systems

## Track D — Language-Specific Deep Dives

- [ ] D1. Clojure's philosophy: data-first, REPL-driven, simplicity
- [ ] D2. Haskell and lazy evaluation: reasoning about purity and performance
- [ ] D3. Rust and ownership: functional safety guarantees in systems code
- [ ] D4. F# in production: pragmatic functional on .NET
- [ ] D5. Elm: functional frontend architecture and the Elm Architecture pattern

## Track E — Cutting edge (rotating)

Items get promoted here from the daily digest when something methodologically new lands. Keep 2-3 max; stale ones get dropped.
