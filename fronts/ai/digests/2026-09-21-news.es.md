En las últimas setenta y dos horas, el enfoque cambió: lejos de escala de modelos, hacia la infraestructura que permite que agents ejecuten de forma segura en producción. Codex Remote de OpenAI continúa remodelando cómo agents remotos se despliegan. El soporte AGENTS.md de Anthropic en Claude Code pasó de curiosidad a práctica standard. Y Model Context Protocol emergió como respuesta pragmática a cómo sandboxear comportamiento de agents.

Simon Willison documentó una historia reveladora esta semana. Alguien de una gran compañía tech publicó sobre uso de Claude Code a escala. Equipos enteros movieron trabajo a Claude Code. Output: ingenieros presionan enter todo el día pero no leen nada. Código shipea. Nadie entiende por qué funciona. Esta es la advertencia.

Ese comentario disparó un pushback necesario. Simon aclaró el valor real de MCP. MCP no es obsoleto. En escenarios donde quieres menos caos que agents con acceso irrestricto, MCP resuelve problemas reales: controlas qué servicios el agent accede; manejás autenticación sin exponer keys; auditás todo lo que el agent hace; proporcionás UI para usuarios conectar servicios third-party seguramente.

El rol de MCP está emergiendo como boundary de seguridad para sistemas agenticos. No una restricción en capacidad, sino una restricción responsable en blast radius.

OpenAI anunció dos moves mayores esta semana. Codex Remote continúa shipeando. Te permite ejecutar agents en una máquina controlándolos desde tu teléfono. Para desarrollo local o testing de modelos en hardware custom, esto es baseline ahora. Y OpenAI Academy se expandió significativamente. Están agregando learning paths estructurados para diferentes roles y skill levels. Esto señala que OpenAI se está moviendo de training one-off a educación de desarrolladores sostenida.

El anuncio de advisory group de matemáticas fue inesperado. OpenAI está convocando matemáticos e investigadores de IA específicamente en cómo IA puede contribuir a descubrimiento matemático y prueba. Esto se sienta en la intersección de razonamiento profundo y verificación formal. También es reconocimiento de que la próxima frontera no es solo generar texto, sino sistemas de razonamiento que avanzen matemáticas formales.

Un contrapunto que vale notar: Databricks compartió análisis de costos sugiriendo que costos de inferencia de Astra saltaron significativamente. Cuando sistemas se despliegan a escala, el costo real se vuelve visible. Optimización de post-training e inferencia ahora importan tanto como capacidad del modelo.

El patrón emergiendo: despliegue de agents seguro, sandboxeado, auditable está reemplazando automatización ad-hoc. AGENTS.md + MCP + autenticación estructurada devienen standards operacionales. El ingeniero que puede diseñar estas restricciones superará al ingeniero que solo ejecuta agents sin control.
