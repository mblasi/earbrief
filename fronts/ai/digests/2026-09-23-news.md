The conventional wisdom about AI has inverted overnight. For five years, everyone assumed training was the bottleneck. Build bigger models, train on more data, scale the GPUs. But the last week of announcements signal a wholesale shift: inference is now the real workload. And continual learning—adapting models in production without retraining—is moving from research to operational systems.

Ben Thompson's essay on the inference shift landed on Thursday. The numbers are stark. In 2024, training costs dominated. By 2026, a typical frontier lab's compute is now split: thirty percent training, seventy percent inference. Reasoning models amplified this. Test-time compute means you can run the same model longer at inference, spending more per query but improving accuracy without retraining. This changes everything about model economics.

OpenAI's research intern announcement is emblematic. They're shipping an agent that costs one thousand dollars per month. That's not training cost. That's inference cost. The agent runs continuously, routes tasks, calls tools, and generates plans. Each cycle costs money. But the value it extracts—for a research organization—justifies the expense. This is the archetype of production agents in 2026.

AgentCore Evaluations added TypeScript support this week. That detail matters because it signals a shift in who's evaluating agents. No longer just researchers with Python notebooks. Now teams building production agents in JavaScript stacks need evaluation frameworks. The tools are following the deployment pattern.

The shift to continual learning is subtler but more important. A team running an agent in production sees failures. Instead of collecting them for manual annotation and a retraining cycle in three months, continual learning loops can update the agent in hours. Some labs are experimenting with this: agent runs, failure is logged, a background job fine-tunes on the failure, the next agent generation uses updated weights. Feedback is now hours, not quarters.

But there's a catch. Continual learning destabilizes your model. You fix one issue and introduce a new one. Version control becomes critical. You need to be able to roll back to yesterday's agent if today's felt wrong. This is where immutable logs and event sourcing become operational requirements, not just elegant abstractions.

The practical implication: the hero era of model training is ending. The next hero is the engineer who can orchestrate inference at scale, manage agent feedback loops, and keep production systems stable while learning continuously. This person doesn't exist yet. They're being invented right now.

Nvidia's push on agentic AI keeps accelerating. Their narrative: you don't need to train your own models anymore. Use ours. But optimize your agents, your reasoning loops, your tool integrations. The value is shifting from models to systems.

The market is splitting. OpenAI and Anthropic compete on models. Everyone else competes on building agent systems that work with those models. Training expertise becomes a commodity. Agent infrastructure becomes the moat.
